## ПР3. Ответы на контрольные вопросы

1. По результату разницы нет: x += 5 это просто более короткая запись для x = x + 5

2. При x++ сначала возвращается старое значение, и только потом x увеличивается на 1. При ++x всё наоборот: сначала идёт увеличение на 1, а потом возвращается уже новое значение

3. Это всегда bool, то есть либо true, либо false

4. Это когда вторая часть выражения не вычисляется, если ответ уже понятен по первой. В && при первом false дальше не проверяется, а в || при первом true тоже останавливается. Например, в name != null && name.Length > 0 при name равном null длина даже не будет проверяться, поэтому программа не упадёт

5. Сначала выполняются умножение и деление: 2 * 3 = 6 и 4 / 2 = 2. Потом остальное слева направо: 10 - 6 = 4, затем 4 + 2 = 6. Итог 6, в программе тоже вышло 6

6. Так код проще читается, не нужно держать в голове приоритет операторов, и ошибиться получается реже
